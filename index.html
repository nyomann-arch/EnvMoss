Bandingkan file .env Anda tanpa meninggalkan browser

EnvMoss membantu menemukan key yang hilang, key duplikat, dan perbedaan value antara dua file environment — sepenuhnya diproses secara lokal di perangkat Anda.

Buka Tool Baca Panduan

Apa yang ditemukan EnvMoss

  • Missing Key ada di Base tetapi belum ada di Target.
  • Orphan Key tambahan yang hanya ada di Target.
  • Duplicate Key yang ditulis lebih dari satu kali dalam satu file.
  • Mismatch Value berbeda antar file — informasi, bukan error.

Privasi by design

File .env Anda tetap berada di browser. EnvMoss tidak mengunggahnya ke server, tidak menyimpannya, dan tidak mengirimkannya ke layanan pihak ketiga.
