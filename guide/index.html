EnvMoss Guide

How to use EnvMoss to compare two environment files locally in your browser.

Getting started

All you need is two environment files — for example a reference file such as .env.example and the file you want to inspect.

EnvMoss runs entirely in your browser. There is nothing to install.

New here? Open the Tool and follow the steps below.

  1. Open the Comparison Tool.
  2. Enter the Base Environment and the Target Environment.
  3. Press Compare to see the results.
  4. Use the outputs to follow up on the results.

Entering Base and Target

EnvMoss compares two sides: Base and Target.

  • Drag and drop a file onto the drop zone.
  • Use the file picker to select a file.
  • Paste the contents into the textarea.

Each side accepts one file or pasted text at a time.

Running a comparison

The Compare button stays disabled until both sides are filled.

Results appear on the board below the inputs.

Clear All empties both inputs and all results.

Understanding the results

Every key is grouped into one of four statuses.

  • Missing Key exists in Base but not yet in Target.
  • Orphan Extra key that exists only in Target.
  • Duplicate Same key declared more than once.
  • Mismatch Same key, different value.

Variable values are never displayed.

Using the outputs

Markdown Checklist

Copy a ready-to-paste task list of every Missing key.

Merged .env

Download a copy of your Target completed with Missing keys.

If the browser blocks clipboard access, the text stays selected.

Supported syntax

EnvMoss understands the common dotenv format.

  • Key names must start with a letter or underscore.
  • Lines starting with # are comments.
  • An optional export prefix is accepted.
  • Values may be wrapped in single or double quotes.
  • Empty lines are ignored; unparsable lines become warnings.

Fictional example

# Fictional example — not a real secret
APP_NAME=demo-app
API_KEY=change-me-in-production
DATABASE_URL=postgres://localhost:5432/demo
export FEATURE_FLAG=true
QUOTED_VALUE="hello world"
EMPTY_VALUE=

Unparsable lines are reported as parsing warnings.

Privacy

The contents of your .env files stay in your browser.

To end a session, press Clear All and close the tab.

This guarantee covers EnvMoss itself.

Troubleshooting

The file could not be read
The file may be locked or corrupted.
Parsing warnings appear
Some lines were skipped.
Copy to clipboard fails
Clipboard permission may be denied.
The download does not start
Check your browser's download settings.

Everything happens locally.
