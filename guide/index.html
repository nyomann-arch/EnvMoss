EnvMoss Guide

How to use EnvMoss to compare two environment files locally in your browser.

Getting started

  1. Open the Comparison Tool.
  2. Enter the Base Environment (usually .env.example) and the Target Environment (the file you want to inspect) via drag-and-drop, the file picker, or copy-paste into the textarea.
  3. Press Compare to see Missing, Orphan, Duplicate, and Mismatch.
  4. Use Copy Markdown Checklist or Download Merged .env to follow up on the results.

Privacy

The contents of your .env files stay in your browser. EnvMoss does not upload them to a server and does not store them permanently.
