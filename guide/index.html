Panduan EnvMoss

Cara menggunakan EnvMoss untuk membandingkan dua file environment secara lokal di browser.

Mulai di sini

  1. Buka Comparison Tool.
  2. Masukkan Base Environment (biasanya .env.example) dan Target Environment (file yang ingin diperiksa) melalui drag-and-drop, pemilih file, atau copy-paste ke textarea.
  3. Tekan Bandingkan untuk melihat Missing, Orphan, Duplicate, dan Mismatch.
  4. Gunakan Salin Markdown Checklist atau Unduh Merged .env untuk menindaklanjuti hasil.

Privasi

Isi file .env Anda tetap berada di browser. EnvMoss tidak mengunggahnya ke server dan tidak menyimpannya secara permanen.
